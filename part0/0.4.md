sequenceDiagram
    participant user
    participant browser
    participant server

    browser->>server: GET /exampleapp/notes
    activate server
    server-->>browser: HTML, CSS, JS
    deactivate server

    Note right of browser: Script loads existing notes for initial render

    browser->>server: GET /exampleapp/data.json
    activate server
    server-->>browser: JSON list of notes
    deactivate server

    user->>browser: Type note text and click Save
    Note right of browser: Browser creates a note object with content + date

    browser->>server: POST /exampleapp/new_note
    activate server
    Note right of server: Server stores the note and assigns an id/timestamp
    server-->>browser: 302 Redirect to /exampleapp/notes
    deactivate server

    Note right of browser: Browser reloads the notes page after redirect
    browser->>server: GET /exampleapp/notes
    activate server
    server-->>browser: HTML, CSS, JS
    deactivate server

    browser->>server: GET /exampleapp/data.json
    activate server
    server-->>browser: Updated JSON list (includes new note)
    deactivate server

    Note right of browser: JS updates the DOM so the new note appears
