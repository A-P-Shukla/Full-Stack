Query Anecdotes — TanStack Query example

Run the JSON Server and the Vite dev server separately.

Start JSON Server (the project includes `server.js` that runs json-server):

```bash
cd part6/query-anecdotes
npm install
npm run server
```

Start the frontend:

```bash
npm run dev
```

The app uses the Fetch API and TanStack Query to load, create and vote anecdotes.
