Routed Anecdotes — exercises 7.1–7.6

Start the JSON Server (provided separately) on port 3001 serving `anecdotes` resource.

Install and run:

```bash
cd part7/routed-anecdotes
npm install
npm run dev
```

Use the `useField` hook from `src/hooks/index.js` in the form and `useAnecdotes` to fetch/add/delete anecdotes.
